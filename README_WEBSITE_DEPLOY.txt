                 🌐 دليل نشر موقع MONOPRICE على الإنترنت 🌐
==============================================================================

هذا المجلد يحتوي على كافة ملفات الموقع الجاهزة للنشر المباشر.
الموقع مشفر ومبني بأحدث تقنيات الويب، وموجه للبوابة السحابية الموحدة:
https://monoprice.depanto2025.workers.dev

طرق النشر المتاحة (مجانية 100%):

الطريقة 1: النشر عبر GitHub Pages
---------------------------------
1. اضغط دبل كليك على الملف [ UPLOAD_TO_GITHUB.bat ] الموجود في هذا الفولدر.
2. ضع رابط المستودع الخاص بك على GitHub (مثلاً: https://github.com/YourName/monoprice-web.git).
3. سيتولى السكربت رفع الملفات فوراً.
4. ادخل على صفحة المستودع في GitHub -> Settings -> Pages -> اختر Branch: main واضغط Save.
5. سيعمل موقعك مباشرة برابط:
   https://YourName.github.io/monoprice-web/

الطريقة 2: النشر الأسرع عبر Cloudflare Pages (خلال 10 ثوانٍ)
------------------------------------------------------------
1. افتح حساب Cloudflare: https://dash.cloudflare.com/
2. من القائمة الجانبية: Workers & Pages -> Create application -> تبويب Pages.
3. اختر "Upload assets".
4. اسحب كامل هذا المجلد (02_WEBSITE_FOR_GITHUB) وأفلته هناك.
5. سيعمل موقعك فوراً مع شهادة SSL مجانية وسرعة فائقة!
